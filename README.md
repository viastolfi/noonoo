# Noonoo

Mental calculation training app.

## Requirements 

- *gpp*
- *make*

## Compile

Compile using `make`. This will install raylib dependencies and compile all files.

Noonoo can currently only be compiled with `Linux x86_64` and `Macos`. Window version coming later (maybe)

## Run

Once compiled, run the program by running `./build/noonoo` command
